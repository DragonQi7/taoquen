氣之稜鏡

當白光完整地穿過稜鏡，五種顏色會平衡地出現。當其中一種缺席——光就不完整。

背景

在中醫裡，五行——木、火、土、金、水——不是比喻，而是一張能量如何在身體中運行的地圖。每一個臟腑、情緒、季節與症狀，都屬於五行之一。當其中一行變弱，整個循環都會受影響——因為五行是依序相生的。

概念

氣之稜鏡是你五行平衡的即時模型。每一行有兩種狀態：平衡——氣自由流動；耗損——臟腑正在發出訊號。拖動任何一行的滑桿，看相生循環即時回應。這不是測驗，而是一面鏡子——讓你看見這個系統實際上有多麼相互連結。

如何使用

從感覺最熟悉的那一行開始——也就是你認得出其症狀的那一行。調整它的氣，觀察下游哪些臟腑亮起來。在課程的每一週結束後使用，追蹤哪些行正在轉變。「氣功練習」按鈕會告訴你動作如何改變這幅圖像。

此工具建立在 Nan Lu 大師於龍之道氣功®中所傳授的五行意識框架之上。僅供教育與自我反思之用——並非臨床診斷。

氣之人體時鐘

你的身體不是靠單一時鐘運轉，而是靠十二個——每個臟腑一個，各有自己兩小時的高峰。

背景

在中醫裡，氣以精確的 24 小時週期流經十二條臟腑經絡。每個臟腑在一個兩小時的時段中迎來氣的高峰。這不是理論——這正是你會在凌晨 3 點醒來、午餐後覺得沉重，或在一天中某個特定時間思緒最清楚的原因。身體在告訴你哪一個臟腑正在活躍。

概念

人體時鐘顯示你臟腑時鐘的即時狀態——此刻哪一個臟腑處於氣的高峰、它主管什麼，以及它表現不佳時會發出什麼訊號。時鐘上的每個臟腑都帶著一則情緒與身體的訊息。當你在某個特定時辰感受到什麼，這個工具會為它命名。

如何使用

在你感到反覆出現的症狀——疲勞、醒來、消化不適、情緒低落——的時段打開這個工具。點選目前處於高峰的臟腑，閱讀它主管什麼、它在要求什麼。在課程期間每週使用，建立一張個人模式地圖，看看哪些臟腑持續在發出訊號。

臟腑時鐘是中醫的基礎原理，在所有龍之道氣功®課程中都會教授。你在這裡注意到的模式，會與課程中的五行功課直接對應。

氣之銀行

你有兩個能量帳戶。大多數人只知道其中一個——而另一個，他們已經透支了好多年。

背景

中醫描述兩種氣：後天之氣——你每天透過食物、呼吸、睡眠與動作所生成的能量；以及先天之氣——你與生俱來、儲藏在腎中的深層體質儲備。後天之氣是你的活期帳戶，先天之氣是你的存款。當日常生活耗盡了活期帳戶，身體就會悄悄開始動用存款。

概念

氣之銀行幫助你看見你的能量實際上從哪裡來——以及你是在累積儲備，還是在花用它。大多數長期疲勞、腎上腺疲勞或持續低能量的人，都在不知不覺中大量動用先天之氣。這個工具讓這個模式變得看得見，並給你一個扭轉它的框架。

如何使用

在每個課程週結束時使用這個工具。反思你的睡眠品質、醒來時的能量、食物選擇與情緒付出。誠實地調整滑桿。顯示的餘額不是分數——而是一個對話的起點。用它來決定接下來一週要優先進行哪些食療飲食與氣功練習。

累積先天之氣的儲備，是龍之道氣功®的核心目標。課程中強腎的動作與季節飲食建議，都直接作用在這個帳戶上。

兩種框架，一個身體

西醫與中醫並不互相矛盾。它們是透過兩個完全不同的鏡頭，看著同一個身體。

背景

西醫透過結構描繪身體——臟器、細胞、生化路徑、可測量的指標。中醫透過功能與能量描繪身體——氣如何流動、在哪裡鬱滯、五行如何互動。兩者都沒有錯。但對於那些檢查結果正常、卻依然覺得不舒服的人來說，只有其中一個框架能給他們答案。

概念

這個工具把兩種框架並排呈現，讓你看見它們如何以不同方式解讀同樣的症狀。西醫眼中的疲勞，與中醫眼中的腎氣不足，描述的是同一個人——但只有其中一方有處理根源的方法。理解兩種框架，能讓你更有見識地參與自己的療癒。

如何使用

選擇一個你正在處理的症狀或病症，看看每個框架如何命名它、尋找什麼、建議什麼。在課程期間，當你正在經歷的某件事還沒有西醫的解釋——卻有中醫的解釋時，把它當作參考。這是一個識讀工具，不是診斷工具。

理解中醫為什麼以這種方式運作，能讓你的練習更深入。Nan Lu 大師常說：身體比我們為了解釋它而建立的任何系統都更聰明。兩個鏡頭合在一起，更接近真相。

你能消化宇宙嗎？

在中醫裡，消化不只是胃裡發生的事。它是身體轉化所攝取的一切的能力——食物、資訊、情緒、經驗。

背景

在中醫裡，脾與胃是核心的消化臟腑——屬於土行。它們主管運化：提取有用的，釋放無用的。但在中醫的觀點中，這不只適用於食物。擔憂、過度思考與未消化的情緒，都在消耗同一個系統。土行虛弱時，會表現為腹脹、飯後疲勞、腦霧，以及難以放下。

概念

這個工具描繪五階段的消化管線——從攝取、轉化到釋放——並顯示大多數人的流程在哪裡出了問題。每一個階段都對應一對特定的臟腑、一種情緒，以及一種輸入。當消化在任何一個階段失敗，身體就會發出訊號。這個工具幫助你找出你的管線在哪裡最強、在哪裡需要支持。

如何使用

逐一檢視這五個階段，留意哪些讓你覺得熟悉。同時注意身體與情緒的症狀——它們對應到相同的臟腑。把課程中的食療飲食指引與這個工具一起使用，看看哪些食物與練習能處理你特定的失衡階段。每個季節回來看看——土行在長夏最脆弱。

脾胃這一對，是龍之道氣功®中最常處理的臟腑組合之一。課程中建議的無極站樁與溫熱食物，能直接滋養這個系統。

寒濕自我檢測

現代健康中最常見的兩種隱藏模式——也是主流醫學最少辨識出的兩種。

背景

在中醫裡，寒與濕不只是天氣狀態——而是經由飲食、生活方式與環境，日積月累形成的體內病理模式。寒會收縮、減緩——導致僵硬、循環差與代謝能量低落。濕會阻滯、沉重——導致身體沉重、遲緩、腦霧與水腫。大多數人兩者都有，卻常常沒有察覺。

概念

寒與濕是中醫六淫中的兩種，可能由外入內——也就是在身體的經絡與臟腑中住下來。一旦入裡，它們就會干擾氣的流動、消化與臟腑之間的溝通。它們在早期並不明顯——這正是它們長期沒有被處理的原因。這個工具幫助你辨識是否存在其中任何一種模式，以及它已經沉積得多深。

如何使用

誠實地為每一個症狀評分，完成自我檢測。結果會顯示你的模式偏寒、偏濕或兩者皆有——以及這個模式目前有多強。把建議與你的課程飲食計劃一起使用。寒的模式對溫熱食物與補陽的氣功有反應；濕的模式對乾燥、煮熟的食物，以及讓氣循脾經運行的動作有反應。

清除寒濕，是龍之道氣功®食療飲食方案的根本目標之一。在六週的過程中，留意你的模式分數如何變化。
